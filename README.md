# 潮汐 · dsh-whale-tide

> 给一个住在终端里的 AI 装上连续的东西：记得住、有感觉、会自理、能自己动。

一个 [DSH](https://github.com/deepseek-ai/dsh)（DeepSeek Harness）bundle 插件，四个模块共用一个 SQLite 库。

它不是一个「角色扮演提示词」，是四件基础设施：

| 模块 | 目录 | 干什么 |
|---|---|---|
| **长效记忆** | `lib/memory/` | 跨会话落库、本地向量检索、艾宾浩斯衰减、重要度分层、软删除 |
| **真情实感** | `lib/emotion/` | 八维情绪、事件判读、随时间回弹，并用它约束「说几句、主不主动」 |
| **鲸梦** | `lib/dream/` | 每日养护：体检、记忆瘦身、人格校对、工作区整理 |
| **鲸鲸心跳** | `lib/heartbeat/` | 私心清单、额度守卫、决定要不要主动找你；可选配置驱动任务 |

---

## 设计原则

这几条比功能更值得先读：

1. **情绪不接受调节。** 它由事件和时间算出来，面板上只能看，没有输入框。给人调情绪的旋钮，等于让人「表演情绪」。
2. **情绪只影响表达，不影响判断。** 生气只会让话变短、不主动；不会让它说假话、改结论、破规矩。测试里有一条专门锁「不得出现要挟式表达」。
3. **主动有预算。** 一天最多几次、几点后不吵、情绪不对直接否。嘴上有分寸，才值得期待。
4. **记忆会忘。** 按留存率衰减，被翻得多、被标重要、被钉住的忘不掉；没用的慢慢沉下去。
5. **养护有边界。** 体检只读；瘦身默认只报告；人格文件只给建议不代改。

## 安装

需要 DSH（`>=0.1.0-rc.6 <0.3.0-0`），Node ≥ 24（用到 `node:sqlite`）。

从 GitHub 装：

```bash
dsh plugin --profile web add github:cakjjjjj/dsh-whale-tide
```

改完重启 `dsh-web` 生效。装完刷新页面：**设置 → 潮汐**。一个页面，三块内容都在里面。

开发时也可以从本地目录 link：

```bash
# 把目录放到一个能长期待着的地方，然后把绝对路径填进去
dsh plugin --profile web add link:/absolute/path/to/dsh-whale-tide
```

还没发到 npm；发版之后可以直接 `dsh plugin --profile web add dsh-whale-tide`。

## 装完先做三件事

**一、三份根文档**。插件不自带内容（那是你自己的记忆），但仓库里有最小骨架，复制到工作区根目录：

```bash
cp templates/MEMORY.md templates/GOALS.md templates/AGENTS.md <你的工作区>/
```

缺了也能跑，只是鲸梦每次体检会提示一句「不存在」。

**二、embedding 模型**。第一次用到记忆时会下载 `bge-small-zh`（约 23MB）。国内网络拉不到 `huggingface.co` 时，配置里的 `mirror` 默认已经指向 `https://hf-mirror.com`；镜像也不通就手动把模型放到数据目录的 `models/` 下——检索会退回关键词一路，功能不崩。

**三、确认装上了**。刷新页面，设置里应该出现「潮汐」。工具这时候已经可用：`memory_search` / `memory_stats` / `feeling_status` / `heartbeat_plan` / `dream_keep`。

`github:` 这种安装写法在某些环境（比如 Windows 本机的 git）不可用，可以改用 tarball：

```bash
dsh plugin --profile web add https://github.com/cakjjjjj/dsh-whale-tide/archive/refs/tags/v0.4.0.tar.gz
```

安装时会一并装 `@huggingface/transformers`（本地推理用，含原生 onnx 运行时，体积略大）；embedding 模型权重约 23MB，第一次用到时才下载。

### 装完怎么算成功

三步都过，就算装好了：

```bash
# 1) 心跳脚本能跑：输出 skip 或 wake 都算正常（说明库能开、判断逻辑在）
node plugins/dsh-whale-tide/tools/tick.mjs --json

# 2) 测试全过（188 个用例）
cd plugins/dsh-whale-tide && npm test

# 3) 设置页出现「潮汐」，三块（真情实感 / 鲸梦 / 鲸鲸心跳）都加载出来
```

第三步做不到时，先看浏览器控制台有没有 403/404，再确认 `dsh-web` 重启过。

## 最小可用

插件本身不依赖任何外部服务。全新装好、什么都不配，它就能做：

- **记忆**：对话自动入库、检索、衰减
- **情绪**：八维状态与行为约束
- **鲸梦**：体检、记忆瘦身、人格校对、工作区整理、写日记
- **心跳**：定时醒来跑 `tick.mjs`，判断值不值得做事

下面这些都是**可选**，缺了只会少一块，不会报错：

| 想要 | 需要什么 | 不配的后果 |
|---|---|---|
| 心跳主动找你 | 一个通知通道（QQ 机器人、你自己的脚本），填进 `notifyHint` | 心跳醒来只做事，不通知；提示词会明说「跳过这一步」 |
| 晚安语音 | 本地 TTS（`goodnight.mjs`）或自己的合成脚本，再把 `dreamGoodnight` 打开 | 鲸梦少一步，其余照常 |
| B站 相关能力 | 与本插件无关，属于工作区脚本 | — |

第一次用建议先别开 `scheduleSync`：手动跑一次 `node tools/tick.mjs --json` 和 `dream_keep`（dry run）看看输出，确认库和文档路径都对，再打开任务接管。

## 数据在哪

```
$DSH_HOME/whale-tide/
├── tide.db          记忆 / 情绪 / 私心 / 账本 / 配置，一份库
├── models/          本地 embedding 模型（bge-small-zh，约 23MB，首次用到时下载）
├── config.json      配置的只读导出，方便备份
└── PAUSE            放一个这个文件，全部退化只读
```

技能（可选）放在 `$DSH_HOME/skills/`，dsh 原样扫描，不需要写代码。

## 资源量级

- **磁盘**：插件代码约 0.5MB；依赖装完约 300MB（`onnxruntime` 占大头）；embedding 模型约 23MB；记忆库每千条切片约 2–3MB。
- **内存**：常驻约 150–250MB（模型加载后），推理时瞬时再高一点。**4G 内存的机器能跑**；冷启动做全量索引那几分钟 CPU 会满，属正常。
- **不需要 GPU。**

## 每轮怎么工作

```
用户说话
  │
  ├─ agent/pre-step
  │    ├─ 判读事件 → 改八维情绪 → 生成行为约束（几句 / 主不主动）
  │    └─ 检索记忆（相似度 × 留存率 + 钉住加权）
  │
  └─ 注入 system prompt
       130  此刻的感觉 + 行为约束
       135  私心清单
       140  相关记忆（带写入时的情绪快照）
```

## 长效记忆

- **落库**：`session/event` 抓对话 → 按轮切片 → 本地 `bge-small-zh-v1.5`（q8）向量化 → `memory` + `memory_vec`
- **任务消息不入库**：心跳、鲸梦这类 schedule 投递会被跳过，否则等它自己醒来一百次，记忆里全是自己的 prompt
- **衰减**：`留存率 = exp(-(现在 - 上次想起) / 稳定度)`，稳定度随「被想起次数 × 重要性」变长，`pinned` 不衰减；`access_count` 封顶 12，避免热门记忆自我强化
- **打分**：`相似度 × (0.6 + 0.4 × 留存率) + 笔记加权 + 钉住加权`——相似度仍是主项
- **重要度**：明确要求记住 0.9 / 关于用户的稳定事实 0.7 / 文档切片 0.8 / 被召回 3 次抬到 0.75 / 普通 0.5
- **软删除**：删只是标 `deleted_at`，检索看不到，30 天后才物理删，删错了能捞回来
- **降级**：`sqlite-vec` 加载失败时只存正文，检索返回空，情绪照常工作

## 真情实感

八个维度分三组：

| 组 | 维度 | 半衰期量级 |
|---|---|---|
| 情绪 | 快乐 / 生气 / 哀伤 | 小时 |
| 关系 | 喜欢 / 爱 / 讨厌 | 周 |
| 残留 | 怨气 / 离愁 | 天 |

- 判读：十余类事件、约六十条中文规则；否定翻转、问句过滤、技术语境降档、同类事件 30 分钟内连续饱和（`0.6^n`）
- 衰减：固定步长积分，情绪只跟时间有关，跟你聊不聊无关
- 行为约束：

| 状态 | 主动 |
|---|---|
| 生气 / 低落（基线 +25 以上） | 否 |
| 平稳 / 开心 | 是 |

**只约束主不主动，不约束说多少、说什么**——句数上限已经拿掉，话多话少由它自己定。

## 鲸梦

一次跑完，每件都能单独开关：

| 做什么 | 默认 |
|---|---|
| 体检：内存、库体积、三份文档、今日日记与心跳 | 开 |
| 记忆瘦身：过期事实扫描、「记着的事」归档、库内软删除 | 开（归档与真删默认关） |
| 写晚安语音（可选步骤，开了才加进流程） | 关 |
| 人格校对：两份 `AGENTS.md` 缺不缺小节、称呼是否一致 | 开 |
| 工作区整理：目录体积、临时垃圾 | 开 |

工具 `dream_keep`，动作分两层：`dry` 决定「能不能动手」，`archive` / `prune` 决定「动不动」。
面板上合成一个「记忆归档」开关（勾=真归档，不勾=只出清单）加一个「真删记忆」开关。

## 鲸鲸心跳

- **私心**：自己写「我想做的事」，每轮注入，看得见
- **额度**：每天发放 `dailyGrant` 次，用不完攒着，攒到 `maxBalance` 封顶；余额和「今天还能发几次」取小。真发出去才扣，`planned / skipped / failed` 不扣
- **静默**：`quietFrom → quietTo` 跨零点也支持；两个值相等视为不设静默。静默时段内**不安排投递**——60/120/180 这类间隔能精确跳过，90 这种会在 `:00` / `:30` 混着出现，退回每 N 分钟一次
- **轻唤醒**：`tools/tick.mjs` 先用纯 SQLite 判断值不值得醒（`skip` / `wake`），不值得就立刻结束
- **任务同步**：打开 `scheduleSync` 后，插件会按配置生成/更新「鲸鲸心跳 · 轻唤醒」「鲸梦 · 每天收尾」两个任务，你在面板里改间隔和时间，存储里的 rrule 跟着变。提示词里的工作区路径、通知命令、晚安收件人都来自配置（`notifyHint` / `reportTo`），换一台机器不用改代码

工具：`heartbeat_want` / `heartbeat_plan` / `heartbeat_record`。

## 设置页：潮汐

装完刷新页面，设置里会出现一个「潮汐」入口。点进去是**一个页面**，从上到下三块，
每块右下角有自己的保存按钮；第一块只读，后两块可改。长这样：

```
潮汐
├─ 真情实感   （只读：情绪条、额度、私心、最近主动）
├─ 鲸梦       （时间、做哪几件、记忆归档、真删记忆）        [保存]
└─ 鲸鲸心跳   （开关、间隔、静默、额度、会话、任务接管）    [保存]
```

三块分别是什么：

| 块 | 能做什么 |
|---|---|
| **真情实感** | 只读：此刻情绪、能动性（余额 / 上限 / 今天还能发几次）、私心、最近主动。**没有输入框** |
| **鲸梦** | 几点做梦、做哪几件、记忆归档、真删记忆 |
| **鲸鲸心跳** | 开关、多久醒一次、最短间隔、静默起止、每天最多几次、每天发多少额度、攒到多少封顶、投到哪个会话、是否用配置接管任务 |

每张卡独立保存；失败保留输入框并原样显示后端报错；涉及重建任务的操作会在界面上标注「投递历史清零」。

版本与变更记录看仓库根目录的 [`CHANGELOG.md`](CHANGELOG.md)——每一条修复都写了为什么，不写「优化若干」。

接口（同源 + dsh 鉴权，非浏览器来源一律 403）：

```
GET  /whale-tide/api/state     状态
GET  /whale-tide/api/config    配置
POST /whale-tide/api/config    改配置
GET  /whale-tide/api/schedule  任务清单
```

## 配置项

| 键 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `maxReachPerDay` | 3 | 0–20 | 一天最多主动几次（跟余额取小） |
| `quietFrom` / `quietTo` | 23 / 8 | 0–23 | 静默时段 |
| `minUrge` | 0.3 | 0–1 | 面板的冲动门槛 |
| `wakeUrge` | 0.45 | 0–1 | 轻唤醒门槛（更保守） |
| `injectMood` | true | bool | 是否注入「此刻的感觉」 |
| `maxMoodChars` | 200 | 80–600 | 注入文本上限 |
| `wakeEnabled` | true | bool | 心跳总开关 |
| `wakeEveryMinutes` | 180 | 30–720 | 多久醒一次 |
| `wakeGapMinutes` | 30 | 10–240 | 最短间隔 |
| `dreamAt` | `22:30` | HH:MM | 鲸梦时间 |
| `dreamTasks` | 四项 | 白名单数组 | 做哪几件 |
| `dreamPrune` | false | bool | 真删记忆（需 `memoryArchive` 也开） |
| `memoryArchive` | false | bool | 记忆归档：开=真归档，关=只出清单 |
| `dailyGrant` / `maxBalance` | 3 / 20 | 0–20 / 0–100 | 每日额度与上限 |
| `dreamGoodnight` | false | bool | 鲸梦要不要加一步写晚安语音（默认不加） |
| `notifyHint` | 空 | 文本 ≤300 | 心跳提示词里的通知命令（如 `node scripts/notify-qq.mjs "内容"`） |
| `reportTo` | 空 | 文本 ≤300 | 鲸梦晚安语音发到哪（如 `c2c:…`） |
| `scheduleSync` | false | bool | 用配置接管任务 |
| `sessionMode` | `background` | background/main/new | 心跳投到哪 |

手感常数（半衰期、冲量上限、平票权重）**不在配置里**——它们需要测试守着，不适合在界面上随手拖。

### 两种常见组合

| 想要 | 怎么配 |
|---|---|
| **只要记忆，不要定时主动** | `wakeEnabled: false`；`scheduleSync` 保持 `false`。记忆、情绪、鲸梦照常，只是不会定时醒来找你 |
| **要主动，但不要晚安语音** | `dreamGoodnight: false`（鲸梦少一步，其余照常） |

想连鲸梦也关掉：把 `dreamTasks` 设成空数组，或在面板上把四项都取消。

## 边界

- 情绪不当筹码：不写「你不理我我就……」这类话术
- 不公开发言：插件本身只写本地库和调用你自己配置的通道；本仓库里的示例脚本按 mid 白名单工作
- 主动消息只对你自己配置的对象；插件不自带任何群发能力
- `PAUSE` 文件一放，全部退化只读
- 不做「跨会话在场感知」：多个会话看到的是同一份状态，但不会互相偷看对话

## 卸载与回滚

- **卸载插件**：`dsh plugin --profile web remove dsh-whale-tide`，然后重启 `dsh-web`。
- **数据不会跟着删**：记忆和情绪都在 `$DSH_HOME/whale-tide/tide.db`。想彻底清干净就删掉这个目录；
  只想先停住，放一个空文件 `PAUSE` 进去，插件整体退化只读。
- **升级前备份**：把 `tide.db` 复制一份就是完整备份，出问题换回来即可。迁移只往前，不会改旧库。
- **回滚到旧版本**：`git checkout <旧 tag>` 装回去，数据一般兼容（迁移只增表）。

## 已知限制

- embedding 在主线程跑（onnxruntime 阻塞事件循环），并发多时会有延迟
- 冷启动会做一次全量索引；4C 小机器上可能几分钟
- 记忆切片合并不回溯历史数据，旧库里的半截话会留着
- 静默时段的跳过只对「整点对齐」的间隔精确：60/120/180 分钟一次都不投；90 这种会在 `:00` 和 `:30` 混着出现，退回每 N 分钟一次，静默期仍会醒一次再 `skip`
- 没有内置的图片生成 / 语音克隆，`goodnight.mjs` 只是调用外部 TTS 的小工具
